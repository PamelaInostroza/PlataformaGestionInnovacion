## Criterios aplicados

- No se distribuyen archivos de datos.
- No se muestran correos, teléfonos ni identificadores reales de terceros.
- Los nombres, avatares, proyectos y áreas visibles son demostrativos o genéricos.
- Se privilegiaron pantallas explicativas e información agregada.
- Las capturas originales se mantienen fuera del contenido versionado.

## Revisión antes de publicar

Si alguna captura se reemplaza, se debe revisar nuevamente:

- nombres y fotografías;
- correos y teléfonos;
- códigos e identificadores;
- montos o detalles de proyectos no públicos;
- pestañas, URLs y elementos del navegador;
- permisos de uso de marca.

No agregues imágenes del sistema institucional sin autorización expresa.
